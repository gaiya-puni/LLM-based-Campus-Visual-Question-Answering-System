### 地标的回填模板

```json
{
  "id": "scene_putuo_liwa_river",
  "category": "scene",
  "subCategory": "校园水体",
  "name": "华东师范大学普陀校区丽娃河",
  "locationName": "丽娃河",
  "lng": 121.405659,
  "lat": 31.227438,
  "campus": "普陀",
  "source": "manual_amap_picker",
  "text": "丽娃河 校河 水岸 河畔 绿树成荫 林荫 地标 风景 取景 拍照 打卡 散步 并肩 慢走 安静 浪漫 约会",
  "tags": ["地标", "河流", "水岸", "林荫", "拍照", "散步", "约会", "普陀"],
  "scenes": ["photo", "walk", "date"],
  "sceneWeight": 1.8,
  "meta": {"address": "普陀校区中部", "notes": "校河，标志性水岸景观"}
}
```

地标类建议 `subCategory` 用**功能化命名**（`校园水体` / `地标建筑` / `历史建筑`）便于同类聚合；
`text` 里同时写进**拍照词**（取景/打卡/风景/地标）与**散步/约会词**（林荫/慢走/并肩/安静），
`scenes` 只声明真正适用的场景。

## 四、新增点位的回填格式

追加到 `webapp/backend/scene_pois.json`（JSON 数组）。必填 `id / category /
subCategory / name / locationName / lng / lat / campus / text / tags`，并额外提供
`scenes` 与可选的 `sceneWeight`：

```json
{
  "id": "scene_minhang_liwa_riverside_bench",
  "category": "scene",
  "subCategory": "河畔长椅",
  "name": "华东师范大学闵行校区图书馆旁河边长椅",
  "locationName": "图书馆旁河边长椅",
  "lng": 121.452914,
  "lat": 31.030308,
  "campus": "闵行",
  "source": "manual_amap_picker",
  "text": "河畔长椅 河畔 水岸 长椅 座椅 落座 安静 私密 并肩 聊天 浪漫 约会",
  "tags": ["长椅", "座椅", "河畔", "水岸", "安静", "浪漫", "约会", "闵行"],
  "scenes": ["date"],
  "sceneWeight": 1.8,
  "meta": {"address": "闵行校区图书馆旁河边", "notes": "河畔长椅，适合约会落座"}
}
```

要点：

- `scenes` 决定参与哪些场景。**同一把椅子不要同时标 `walk` 和 `date`** —— 两个场景若共用
  同一批点位，区分度不会提升。收益来自"分工"。
- `text` / `tags` 直接决定向量相似度，必须写进**场景词**：
  散步用 `散步 慢走 乘凉 林荫 开阔 落座`；约会用 `并肩 浪漫 安静 私密 水岸 傍晚`。
  只写"长椅"会导致相似度偏低、排名靠后、`beta` 被截断为 0 而完全不贡献。
- `sceneWeight` 建议 1.4–2.2；过大（>2.2）容易让个别点位喧宾夺主。
- 点位要**铺开在不同片区**，不要集中在一处，否则峰位仍然重合。
- 坐标一律高德 GCJ-02、6 位小数。

回填后需要重建（`scene_pois.json` 参与哈希，不重建不会生效）：

```powershell
cd webapp/backend
python build_semantic_index.py     # 点位进入检索索引（默认只用本地模型）
python build_scene_heatmaps.py
python evaluate_scene_heatmaps.py --sensitivity
```
